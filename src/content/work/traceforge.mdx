<CaseStudySection id="problem" title="Problem">
  <CaseStudyCopy>
    Distributed systems generate trace data across multiple services. The trace
    context has to survive hops between services, ingestion boundaries, event
    transport, processing consumers, and storage so diagnostics remain useful.
  </CaseStudyCopy>

  <CaseStudyCopy>
    The system design needs to keep ingestion decoupled from downstream
    processing, make buffering and backpressure visible, and expose enough
    operational signal to reason about consumer lag, ingestion behavior,
    processing latency, and end-to-end trace latency.
  </CaseStudyCopy>
</CaseStudySection>
